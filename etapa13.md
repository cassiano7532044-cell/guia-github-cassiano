# ETAPA 13 – PRINCIPAIS COMANDOS DO GIT

**1. git --version**
Função: verificar a versão do Git.
Exemplo: `git --version`
Resultado: mostrar a versão instalada.

**2. git config**
Função: configurar nome e e-mail.
Exemplo: `git config --global user.name "João"`
Resultado: salvar o nome do usuário.

**3. git init**
Função: iniciar um repositório.
Exemplo: `git init`
Resultado: criar um repositório local.

**4. git clone**
Função: copiar um repositório.
Exemplo: `git clone https://github.com/usuario/projeto.git`
Resultado: baixar os arquivos.

**5. git status**
Função: verificar alterações.
Exemplo: `git status`
Resultado: mostrar o estado dos arquivos.

**6. git add**
Função: preparar arquivos para o commit.
Exemplo: `git add .`
Resultado: preparar as alterações.

**7. git commit**
Função: registrar alterações.
Exemplo: `git commit -m "Primeira alteração"`
Resultado: salvar um registro das mudanças.

**8. git log**
Função: consultar o histórico.
Exemplo: `git log`
Resultado: mostrar os commits.

**9. git branch**
Função: listar ou criar branches.
Exemplo: `git branch desenvolvimento`
Resultado: criar uma branch.

**10. git switch**
Função: mudar de branch.
Exemplo: `git switch desenvolvimento`
Resultado: acessar a branch escolhida.

**11. git merge**
Função: unir alterações.
Exemplo: `git merge desenvolvimento`
Resultado: incorporar alterações à branch atual.

**12. git pull**
Função: buscar atualizações.
Exemplo: `git pull origin main`
Resultado: atualizar o projeto local.

**13. git push**
Função: enviar commits ao GitHub.
Exemplo: `git push origin main`
Resultado: enviar as alterações ao repositório remoto.
