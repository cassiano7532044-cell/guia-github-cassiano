## 3. O que cada símbolo faz?

| Markdown | O que aparece |
|---|---|
| `# Título` | Título grande |
| `## Subtítulo` | Subtítulo |
| `**texto**` | **Negrito** |
| `*texto*` | *Itálico* |
| `- item` | Lista |
| `[texto](link)` | Link clicável |
| `![texto](imagem)` | Imagem |
| `\|` | Tabela |
| `` `código` `` | Código |
| `>` | Citação |
